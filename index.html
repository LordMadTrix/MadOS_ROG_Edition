Installation de A à Z

MadOS ROG Edition a été minutieusement conçu pour s'installer sur une base Ubuntu Server 25.10 vierge. Voici pourquoi et comment procéder.

❓ Pourquoi Ubuntu Server et non Desktop ?

Bien que MadOS fonctionne techniquement sur Ubuntu Desktop, Ubuntu Server est vivement recommandé. La version "Desktop" de Canonical vient chargée de centaines de paquets inutiles (Snapd intrusif, télémétrie, processus GNOME tournant en arrière-plan).

En partant d'une base Ubuntu Server, nous garantissons un système 100% pur. MadOS va bâtir sa propre surcouche graphique (KDE Plasma 6 ultra-personnalisé) à partir du néant absolu. Résultat ? Une RAM divisée par deux au repos, zéro bloatware, une latence réduite et une fluidité absolue en jeu !

1
Préparation Média
  • Téléchargez l'ISO officielle Ubuntu Server 25.10.
  • Flashez-la sur une clé USB avec un outil comme Rufus, BalenaEtcher ou Ventoy.
  • Démarrez votre ASUS ROG sur cette clé USB (touche Echap ou F8 au logo ASUS).
2
OS Serveur Basique
  • Pendant l'installation, choisissez l'installation standard (pas la version "minimale" pour éviter l'absence d'outils réseaux).
  • Ne cochez AUCUN paquet optionnel (ni Docker, ni serveurs annexes).
  • Créez simplement votre profil utilisateur (qui deviendra l'Administrateur).
3
Injection Cyberpunk
  • Redémarrez, et connectez-vous dans la console noire avec les identifiants que vous venez de créer.
  • Assurez-vous qu'internet fonctionne.
  • Tapez cette commande magique de nouvelle génération :
    wget -qO install.sh https://raw.githubusercontent.com/LordMadTrix/MadOS_ROG_Edition/main/install.sh && sudo bash install.sh
⚠️

Avertissement & Disclaimer

MadOS ROG Edition est un projet communautaire gratuit et open-source. Ce puissant framework modifie des composants critiques de votre matériel (Kernel, options de démarrage, VBIOS, courbes de ventilation, undervolting via RyzenAdj/Intel). L'auteur (LordMadTrix) et les contributeurs déclinent toute responsabilité formelle en cas de dommages matériels, pertes irréversibles de données ou surchauffes accidentelles. L'installation de logiciels de bas niveau, la gestion du MUX Switch et la manipulation des voltages comportent toujours un facteur de risque inhérent. Vous utilisez ces outils à vos propres risques. Lisez toujours les menus avant de les valider.
