## ⚡ COMMANDES CLI (`mados`)
Utilisez ces commandes dans votre terminal préféré (**Konsole/Zsh**) :

### Hardware & Profils
* `mados shift game` : Pousse le i9 et la RTX à leur maximum.
* `mados shift eco` : Idéal pour le calme et la batterie.
* `mados night on` : Filtre bleu + RGB minimal pour vos yeux.

### Système & Diagnostic
* `mados guide` : Réaffiche ce pense-bête dans le terminal.
* `mados logs` : Affiche les 20 dernières lignes du log d'installation.
* `mados check` : Lance le benchmark et le diagnostic santé.

### Store (Installation Éclair)
* `mados store steam`
* `mados store discord`
* `mados store heroic`

## 🧠 FONCTIONS "GOD-TIER" ACTIVES
Ces technologies tournent en fond pour garantir votre supériorité technique :

1. **PROTEC-THERM (Thermal Guard)** : Si vos composants atteignent **90°C**, MadOS vous prévient vocalement et force les ventilateurs au maximum.
2. **QoS GAMER (e-Sport Stack)** : La pile réseau est modifiée pour donner la priorité absolue à vos paquets de jeu (Anti-Bufferbloat).
3. **ZRAM 2.0 (ZSTD)** : Pas de swap sur SSD. Tout est compressé en RAM pour une réactivité instantanée.
4. **HUGEPAGES (2GB)** : La mémoire est pré-réservée pour les moteurs de jeux lourds, évitant les micro-freezes.
