MadOS ROG Edition

Le Guide d'Installation Ultime (Mode Clé USB Offline)

⚠️ PRÉREQUIS BIOS TRÈS IMPORTANTS

Avant d'insérer la clé et de démarrer, vous DEVEZ configurer votre BIOS ASUS (Touche F2 ou Suppr au démarrage) :
- Secure Boot : Désactivé (Disabled) (Crucial pour les pilotes NVIDIA et les contrôles ventilateurs)
- Fast Boot : Désactivé (Disabled)

1

01 Démarrer sur la clé USB

Insérez la clé USB contenant l'ISO d'Ubuntu Server 24.04 (Noble Numbat) que vous avez flashée (avec Rufus ou Balena). Si vous n'avez pas encore Ubuntu Server, téléchargez-le et mettez-le sur une autre clé USB.

  • Allumez le PC et tapotez Echap ou F8 pour ouvrir le Boot Menu.
  • Sélectionnez votre clé USB en mode UEFI.
  • Lancez l'installation d'Ubuntu Server.
2

02 Installation d'Ubuntu Server

L'installateur en ligne de commande apparaît. Suivez ces règles d'or :

  • Langue : Choisissez Français.
  • Version : Prenez Ubuntu Server (Normal), pas la version minimisée.
  • Disque : Choisissez "Use an entire disk" pour effacer tout et mettre MadOS, ou "Custom storage layout" si vous faites un Dual Boot avec Windows.
  • Identifiants : Mettez un nom d'utilisateur simple (ex: mados) et un mot de passe dont vous vous souviendrez. Nommez le serveur : mados-rog.
  • Services : 🔴 NE COCHEZ AUCUN SERVICE SUPPLÉMENTAIRE NI SNAPS À LA FIN. Le système doit rester totalement vide.

Laissez l'installation se terminer. Quand on vous le demande, retirez la clé Ubuntu, et faites Reboot Now.

3

03 Connexion et Lancement de MadOS

Votre PC va redémarrer sur un écran noir vous demandant votre login. C'est normal, c'est un serveur vierge.

  • Tapez votre nom d'utilisateur et validez.
  • Tapez votre mot de passe (les lettres ne s'affichent pas, c'est normal sous Linux) et validez.
  • Maintenant, insérez la clé USB "MADOS" (celle qui contient ce tutoriel).

Tapez exactement cette commande pour lancer la magie, en remplaçant $USER par votre nom d'utilisateur :

bash /media/$USER/MADOS/start.sh

Astuce : Si ça ne marche pas, vous pouvez taper lsblk pour voir vos disques, ou essayer bash /media/mados/MADOS/start.sh

4

04 La Matrice prend le contrôle

L'interface graphique MadOS ROG Edition (Cyberpunk Red/White) va se lancer au milieu de votre terminal noir.

  • Sélectionnez "Déploiement Total" pour une installation E-Sport complète.
  • Laissez le système travailler pendant 15 à 25 minutes. Il va compiler le noyau XanMod autonome, configurer votre carte NVIDIA, installer KDE Plasma 6 Wayland, et optimiser votre réseau TCP BBR pour le gaming.
  • Ne touchez à rien jusqu'à l'écran de succès.

À la fin, tapez simplement :

sudo reboot

L'univers sombre d'Ubuntu Server laissera place au démarrage fulgurant de KDE Plasma 6 - MadOS ROG Edition. Bon jeu.
