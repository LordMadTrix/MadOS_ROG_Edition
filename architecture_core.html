Spécifications : MadOS 3.2 Ultimate

Ce document détaille les entrailles du framework MadOS. Chaque ligne de code est pensée pour maximiser le rendement matériel des configurations ASUS ROG (i9 / RTX) sous un environnement Linux minimaliste.

🚀 Le Propulseur : Moteur Nala

MadOS remplace le gestionnaire de paquets par défaut (APT) par Nala. Cela permet un téléchargement parallèle sur les 16 meilleurs miroirs détectés dynamiquement.

# Dans MASTER_INSTALL.sh
ensure_nala() {
    sudo apt update && sudo apt install -y nala
    alias apt='sudo nala'
}
  • Réduction de latence : Choix automatique des serveurs les plus proches.
  • Parallélisation : Jusqu'à 16 flux simultanés (gain de temps de ~400%).

💎 Moteurs "God Tier" (Spécifications)

Extreme

🏁 Module 31 : Turbo-Tuner

Le cœur de l'optimisation hardware. Ce module reconfigure dynamiquement le kernel pour les architectures i9 hautes fréquences.

  • Hugepages : Allocation massive de 4096 pages pour les jeux VR et AAA, réduisant les défauts de cache mémoire.
  • PCI Latency : Ajustement des timers de latence PCI pour que la RTX puisse "parler" au CPU sans file d'attente logicielle (Passage de 64 à 32 cycles).
  • IO Scheduler : Force l'ordonnanceur BFQ sur les disques NVMe pour prioriser l'accès aux données de jeux par rapport aux processus système.
Stable

🛡️ Module 32 : Stealth-Mode

Hardening complet du système pour une confidentialité totale.

  • DNS-over-TLS : Cryptage de toutes les requêtes DNS via Quad9 (Encapsulation TLS 1.3).
  • Anti-Telemetry : Purge nucléaire des paquets apport, popularity-contest et blocage des rapports d'erreurs Canonical.
  • Firewall Caméléon : Configuration UFW fermée par défaut, avec ouverture adaptative pour Steam et les connexions LAN synchronisées.
Stable

🧠 Module 29 : MadChat IA

Intégration locale d'IA générative directement sur le GPU.

# Configuration Ollama via RTX
systemctl enable --now ollama
ollama run mistral

L'IA utilise les Tensor Cores de la RTX pour une génération de texte à ~50 tokens/sec, sans aucune connexion cloud.

🧱 Architecture de l'Installeur

🛠️ L'Orchestrateur Modulaire

L'installeur utilise un système de "Traps" et de "Locks" pour garantir qu'aucune installation ne se chevauche.

  • wait_for_apt : Boucle de surveillance des verrous DPKG pour éviter les erreurs "Another process is using this file".
  • Modularité : Les 36 modules sont isolés. Un échec sur le module 'Son' n'empêche pas l'installation du 'Noyau'.
  • Rollback : En cas d'erreur critique, MadOS génère un rapport complet dans /var/log/mados/mados_errors.log.

🎮 Pile Gaming & Graphique

MadOS force l'utilisation des derniers standards de performance graphique.

  • Wayland par défaut : Utilisation de KDE Plasma 6 sur Wayland pour une fluidité sans déchirement (Zero Tearing).
  • VRR (Variable Refresh Rate) : Pré-activé pour les écrans G-Sync/FreeSync des laptops ROG.
  • MangoHud ROG : Profil personnalisé affichant le Framerate, la Température GPU et la Charge CPU en overlay néon rouge.
