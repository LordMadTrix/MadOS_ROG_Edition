=========================================================
  MadOS ROG Edition 3.0 - COMMANDES DE MONTAGE VMWARE
=========================================================

Ces commandes vous permettent d'accéder à votre dossier Windows (ce projet)
depuis l'intérieur de votre VM Ubuntu / MadOS.

--- [ 1. MONTAGE MANUEL (RECOMMANDÉ) ] ---

# Créer le dossier cible (une seule fois)
sudo mkdir -p /mnt/hgfs

# Activer le montage FUSE pour le partage "mados"
sudo vmhgfs-fuse .host:/mados /mnt/hgfs -o allow_other -o uid=$(id -u) -o gid=$(id -g)

# Vérifier si les fichiers sont là
ls /mnt/hgfs

cd  /mnt/hgfs

--- [ 2. MONTAGE AUTOMATIQUE (AU REDÉMARRAGE) ] ---

# Pour que le dossier soit présent à chaque boot, tapez :
sudo nano /etc/fstab

# Puis ajoutez cette ligne TOUT À LA FIN (avec précaution !) :
.host:/mados /mnt/hgfs fuse.vmhgfs-fuse allow_other,uid=1000,gid=1000,auto_unmount 0 0

# Testez le fstab pour éviter les erreurs de boot :
sudo mount -a

--- [ 3. DIAGNOSTIC SI ÇA NE FONCTIONNE PAS ] ---

1. Vérifier que VMware voit bien le partage :
   vmware-hgfsclient
   --> Il doit répondre "mados"

2. Relancer les outils VMware si besoin :
   sudo systemctl restart open-vm-tools

3. S'assurer que le module FUSE est chargé :
   sudo modprobe fuse
